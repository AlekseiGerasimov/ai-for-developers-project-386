# Запись на звонок

Сервис, в котором гость записывается на звонок с владельцем календаря.

## Язык проекта

**Владелец календаря**:
Человек, с которым гости назначают встречи. В сервисе один заранее заданный владелец календаря.

**Гость**:
Человек, записывающийся на звонок с владельцем календаря без регистрации и отдельного профиля. Имя и email гостя относятся к каждой его записи.
_Избегать_: клиент, зарегистрированный пользователь.

**Тип встречи**:
Предложенный владельцем формат звонка с названием, описанием и длительностью.
_Избегать_: услуга, встреча (когда речь о формате звонка).

В обращении к гостю допустимы краткие формулировки «Выбрать встречу» и
«Выберите встречу» для выбора типа встречи.

**Каталог типов встреч**:
Публичный список типов встреч, из которого гость выбирает подходящий формат звонка.
_Избегать_: каталог встреч, список услуг.

**Запись**:
Бронирование гостем времени для встречи с владельцем календаря. Успешная запись сразу означает подтверждённую встречу, без промежуточного ожидания подтверждения.
_Избегать_: регистрация (в значении бронирования времени).

**Встреча**:
Запланированный звонок определённого типа между гостем и владельцем календаря на конкретное время.
_Избегать_: тип встречи (когда речь о запланированном звонке).

**Окно записи**:
Сдвигающийся с текущей датой диапазон календарных дней, в пределах которого гость может выбрать время для встречи. Даты определяются по часовому поясу владельца календаря.
_Избегать_: окно из рабочих дней.

**Слот**:
Интервал для встречи выбранного типа с определёнными началом и окончанием. Свободный слот соответствует правилам записи и не пересекается с уже назначенными встречами.
_Избегать_: время начала (когда имеется в виду весь интервал).

**Шаг стартов**:
Расстояние во времени между соседними возможными началами встреч в сетке рабочего дня. Не определяет длительность встречи.
_Избегать_: длительность слота (в значении шага стартов).
