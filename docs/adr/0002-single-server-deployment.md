# Один сервер для страниц и API

Собранное приложение распространяется одним Spring Boot JAR: Maven включает содержимое `frontend/dist` в статические ресурсы, а Spring Boot отдаёт страницы и API с одного адреса. Вместо раздельного размещения фронтенда и API выбираем один процесс и один артефакт, чтобы упростить запуск небольшого учебного приложения; Node.js требуется только при сборке.

Публичный путь `/meetings` направляется на `index.html`, чтобы прямое открытие и обновление каталога запускали React-приложение. Неизвестные API и отсутствующие ресурсы сохраняют ответ 404. При разработке сохраняется Vite с прокси API; добавляя публичные страницы, необходимо явно добавлять их серверные маршруты.
